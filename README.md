# Jako × Baran Group

Seven-slide presentation, including the TerraFirma video and all local fonts and images.

Open `index.html` in a browser. Keep the `assets` folder beside it.

## Controls

- Arrow keys or click: move between slides.
- Right-click: previous slide.
- F: full screen.
- N: speaker notes.
- R: restart the video.
- Home / End: first / last slide.

The deck uses a 1920 × 1080 canvas and scales to the browser window.
